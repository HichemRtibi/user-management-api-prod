 LES POINTS CLÉS À RETENIR POUR L'ENTRETIEN
Question 1 : "Comment avez-vous mis en place le monitoring ?"
Réponse : J'ai utilisé Spring Boot Actuator avec Micrometer. J'ai ajouté les dépendances, configuré les endpoints dans application.properties, et sécurisé l'accès avec Spring Security. J'ai créé deux types de métriques : des métriques métier manuelles pour les inscriptions/connexions, et des métriques techniques avec AOP pour mesurer automatiquement le temps des méthodes.

Question 2 : "Quelle est la différence entre les métriques manuelles et AOP ?"
Réponse : Les métriques manuelles sont pour des événements métier spécifiques (inscriptions, connexions) où je contrôle précisément quand incrémenter. L'AOP est pour des métriques techniques génériques (temps de réponse) où je veux mesurer toutes les méthodes sans dupliquer le code.


Question 3 : "Comment accédez-vous aux métriques ?"
Réponse : Toutes les métriques sont exposées via /actuator/metrics. Les métriques sont au format Prometheus pour une intégration future avec Grafana. Les endpoints sensibles sont protégés avec le rôle ADMIN.

Question 4 : "Quels sont les avantages de cette approche ?"
Réponse : Les avantages sont : monitoring en temps réel, détection rapide des problèmes de performance, code propre avec l'AOP, métriques métier et techniques, et facilité d'intégration avec Prometheus/Grafana.
