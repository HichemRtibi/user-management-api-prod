# PRÉPARATION
# -----------
# 1. Créer un Environment Postman :
#    - Nom : UserManagement - DEV
#    - Variables :
#      - baseUrl : http://localhost:8080
#      - adminToken : (à remplir après login)
#      - productId : (à remplir après création)
#      - categoryId : 1

# 2. Démarrer l'application Spring Boot

# 3. Tous les tests utilisent le token admin


# ================================================================
# ÉTAPE 1 : SE CONNECTER
# ================================================================

### LOGIN - Obtenir le token admin
POST {{baseUrl}}/api/auth/login
Content-Type: application/json

{
    "email": "admin@example.com",
    "motDePasse": "Admin123!"
}

# RÉPONSE ATTENDUE : 200 OK
# {
#     "token": "eyJhbGciOiJIUzI1NiJ9...",
#     "type": "Bearer",
#     "utilisateur": { ... }
# }
# ⚠️ Copier le token dans adminToken

# 1. TESTS GET /api/products (Liste paginée)

# {
#     "content": [...],

#     "size": 5
# }

# RÉPONSE ATTENDUE : 403 Forbidden

# ================================================================
# 4. TESTS POST /api/products (Création)
# ================================================================

### 4.1 - Créer un produit avec succès
POST {{baseUrl}}/api/products
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "Smart TV Samsung 55\" 4K",
    "description": "Téléviseur 4K Ultra HD avec Smart TV et HDR",
    "price": 799.99,
    "quantity": 8,
    "imageUrl": "https://example.com/samsung-tv.jpg",
    "categoryId": 1
}
# RÉPONSE ATTENDUE : 201 Created
# {
#     "id": 18,
#     "name": "Smart TV Samsung 55\" 4K",
#     "price": 799.99,
#     "quantity": 8,
#     "category": { "id": 1, "name": "Électronique" }
# }
# ⚠️ Copier l'ID dans productId


### 4.2 - Créer avec catégorie inexistante (Erreur 404)
POST {{baseUrl}}/api/products
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "Produit Invalide",
    "description": "Catégorie inexistante",
    "price": 99.99,
    "quantity": 5,
    "categoryId": 999
}
# RÉPONSE ATTENDUE : 404 Not Found


### 4.3 - Créer avec données invalides (Erreur 400)
POST {{baseUrl}}/api/products
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "",
    "description": "Nom vide",
    "price": -10,
    "quantity": -5,
    "categoryId": null
}
# RÉPONSE ATTENDUE : 400 Bad Request


### 4.4 - Créer sans token (Erreur 403)

    "quantity": 5,
