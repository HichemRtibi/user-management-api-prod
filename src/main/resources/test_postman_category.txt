# ================================================================
# 6. TESTS POST /api/categories (Création)
# ================================================================

### 6.1 - Créer une catégorie avec succès
POST {{baseUrl}}/api/categories
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "Jardinage",
    "description": "Outils et accessoires de jardin"
}
# Résultat : 201 Created avec la catégorie créée

### 6.2 - Créer une catégorie avec un nom existant (Erreur 409)
POST {{baseUrl}}/api/categories
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "Électronique",
    "description": "Duplicata"
}
# Résultat : 409 Conflict

### 6.3 - Créer avec des données invalides (Erreur 400)
POST {{baseUrl}}/api/categories
Authorization: Bearer {{adminToken}}
Content-Type: application/json

{
    "name": "",
    "description": "Nom vide"
}
# Résultat : 400 Bad Request
